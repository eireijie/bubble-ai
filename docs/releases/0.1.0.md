Already have Wisp? It updates itself to Bubble AI. Your chats, agents and memory stay where they are.

## What's new

- **New name.** Wisp is now Bubble AI: the apps, the command line (`bubble-ai`, with `wisp` still working), the data folders and the repository. Old installs move over on their own.
- **New icon.** A round glass bubble with two eyes, on Mac, Windows, Linux, iPhone and Android.
- **Bubbles.** Agents are bubbles now, and the sidebar is a list of chats you can pin and sort into sections.
- **Show me around.** A short tour of the app. It starts after setup, and you can replay it from Help.
- **Teach saves a skill.** Show an agent a task once and it saves the steps as a skill. It offers to run it on a schedule only if you want that.
- **Motion.** The bubble spins in on launch, bobs while loading, hops when something goes well, and its eyes follow the pointer. Reduce motion in Settings turns it down.
