## What's new

- **Chats like Messages.** Your messages on the right, the agent's on the left, a glass sidebar and header, and one message bar.
- **Backgrounds.** None, a photo or a colour. Set the default in Settings or give one agent its own.
- **Pinned agents** sit at the top of the sidebar. A blue dot means an agent needs you.
- **Same-size avatars** for every shape.
- **One agent profile.** Activity, Library, Computer, Voice, Background and Settings. Click the avatar to change its look, hover the name to rename.
- **Plain names.** Model, Harness, Computer, Permissions, Memory.
- **Agents can use this Mac.** First run asks for the permissions once, then your agents can use this computer while it's on.
- **Each agent has its own screen** on the shared computer, and you can watch each one.
